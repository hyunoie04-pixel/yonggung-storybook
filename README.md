# 상자에 남은 질문 · 용궁부연록 웹 스토리북

팀 고전파(古典波) · 고전소설론(허순우 교수) · 「AI와 만난 인문학 수업」

김시습의 〈용궁부연록〉 다섯 장면을 AI 영상으로 보고, 작가 김시습에게 그 뜻을 직접 묻는 12쪽짜리 발표용 웹 스토리북입니다.

## 열기
- **링크로 보기**: GitHub Pages 주소로 열면 어느 컴퓨터에서든 열립니다. 크롬 권장.
- **파일로 보기**: `index.html` 더블클릭. 인터넷이 필요 없습니다.
- 챗봇은 외부 API 없이 브라우저 안에서 답합니다. 입력한 질문을 `js/data.js`의 질문·답변(대표 질문, 다른 말투, 핵심 낱말)과 비교해 가장 가까운 답을 고르고, 애매하면 가까운 질문을 단추로 되묻습니다.
- (선택) `실행.bat` 또는 `node server.js`로 이 PC에서 주소로 열 수 있습니다.

## 조작
| 키 | 동작 |
|---|---|
| ← / → , PageUp / PageDown | 이전 / 다음 쪽 |
| Space, Enter | 장면 쪽: 재생 · 일시정지, 대화 중에는 다음 대사 |
| S | 대화로 넘어가기 |
| R | 장면 다시 보기 |
| F | 전체 화면 |
| Home / End | 처음 / 끝 |

## 고지
- 영상과 김시습의 모습은 AI로 생성한 창작 시각화이며, 실제 풍경·인물의 재현이 아닙니다.
- 챗봇 답변은 수업에서 배운 교수님의 해석을 위주로 생성한 AI 역할극이며, 김시습이 직접 남긴 말이 아닙니다.

## 파일
- `js/data.js` 모든 문안, 자막, 질문과 답변
- `js/main.js` 쪽 구성, 영상과 대화 흐름
- `js/fx.js` 물 효과, `js/art.js` 먹그림 모티프, `css/book.css` 디자인
- `videos/` 장면 영상 5편, `assets/` 김시습 상상 초상과 팀명 붓글씨
